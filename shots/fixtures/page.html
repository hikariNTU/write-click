A page to draw over

Nothing here reacts to the gesture. That is the point: the overlay is drawn above whatever the tab happens to be showing, and takes no pointer events of its own.

Holding the trigger

The stroke is drawn in the page's own coordinates, so it follows the cursor exactly. Only its thickness answers to the overlay scale — page zoom would otherwise make the line fatter as the page grows.

The readout in the middle names whatever the stroke currently matches, and updates as the stroke changes. An unrecognised stroke says so rather than guessing.

A close-to-the-side command counts the tabs it would actually close, using the same filter the background uses, so the number shown and the number closed agree.

Where things sit

The tab grid docks to the top edge and the gesture list to the bottom, which leaves the middle of the window to the stroke being drawn. Try D then L for back, or hold still and let the grid open.

Everything above lives in a closed shadow root, so none of the page's own styles reach it and none of its styles reach the page.
